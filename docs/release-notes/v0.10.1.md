## 修复

- **安装版百炼配额报「env: node: No such file or directory」**：v0.10.0 从 Finder 启动时，应用继承 macOS 精简 PATH（不含 homebrew），bl 本体虽已按绝对路径找到，但 bl 是 node 脚本、启动时还需再找一次 node，导致百炼 Coding / Token Plan 两路在安装版上全部查询失败（终端 dev 环境 PATH 齐全故未暴露）。现给 bl 子进程 PATH 前置 /opt/homebrew/bin 与 /usr/local/bin 并保留原 PATH 兜底自定义安装，安装版与终端行为一致。
- **node 缺失提示改为中文引导**：若 node 装在自定义位置（如 nvm）仍找不到，面板不再抛原始 env 报错，而是提示安装 node 或把 node 目录加入 PATH 后重启应用。
