## 新功能

- **主窗口高度自适应**：窗口高度不再固定 600px，而是跟随内容自动调整——内容用不满时窗口向上收缩，内容增多时自动长回；600px 仍为最大高度，宽度 720 不变，加载与空态保持原高不跳动。供应商较少时，窗口不再拖着一截空白
- **状态栏菜单新增 Skill & Plugin 入口**：托盘菜单可直接进入 Skill & Plugin 页面，主页顶部的对应按钮移除，入口集中在托盘菜单

## 优化

- **主页标题栏更紧凑**：标题栏高度约 57px 降至 45px，给内容腾出更多空间
- **固定背景在矮窗口下不再变形**：背景图改按原始比例裁剪（顶部对齐），窗口收缩后不再竖向压扁，600px 高度下观感与旧版一致
