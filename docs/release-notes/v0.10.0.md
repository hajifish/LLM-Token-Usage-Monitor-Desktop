## 新增

- **百炼 Coding Plan 配额监控**：新增免密供应商「百炼 Coding Plan」（菜单栏短码 BC），自动读取本机百炼官方 bl CLI 的控制台登录态，展示 5 小时 / 每周 / 账单月三个窗口的模型调用次数剩余与重置倒计时，无需在应用里填 API Key。
- **百炼 Token Plan 配额监控**：新增免密供应商「百炼 Token Plan」（菜单栏短码 BT），展示订阅月等窗口的已用占比、剩余百分比与重置倒计时（Essential 等档位适用），同样无需填 Key。
- **使用前提**：安装百炼官方 `bl` CLI 并运行一次 `bl auth login --console`（浏览器登录一次即可）。未安装 / 未登录 / 无对应订阅时，面板会给出明确的中文引导，不会静默无数据。
- **口径说明**：百炼的按量计费 / Coding Plan / Token Plan 是三套互不相通的体系，本版接入后两者的订阅配额通道；按量计费余额无公开查询接口，不在接入范围。Coding Plan 与 Token Plan 请按需各自启用，未订阅的那一路会如实提示「无有效订阅」。
- **安装版兼容**：macOS 从 Finder 启动的应用继承精简 PATH（不含 homebrew），bl 查找已做绝对路径优先（/opt/homebrew/bin → /usr/local/bin）再回退 PATH，安装版与终端 dev 行为一致；失败文案取人话首行、限长，网络超时不会被误报为「未登录」。
