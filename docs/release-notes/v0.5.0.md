## 新功能

- **供应商配置独立页**：主页右上角「+」进入，供应商的添加、编辑、删除、别名与类型切换独立成页；设置页专注全局设置（菜单栏显示指标 / 点击图标打开主页 / 余额告警逐级通知），全部即时生效
- **点击菜单栏图标直接打开主页**（新开关）：开启后左键点击托盘图标直达主窗口；窗口已打开时点击则弹出详情菜单；右键始终可打开详情菜单
- **托盘菜单新增「设置」入口**：无需先开主页，从菜单栏直达设置页
- **固定背景**：新背景方案（跟随系统 / 固定背景，旧配置自动兼容）

## 改进与修复

- 修复供应商别名输入时每敲一个字符就失焦、无法输入的问题
- 新增供应商后返回主页立即显示「加载中」占位卡片，数据到达后自动补齐——慢供应商也能马上确认添加成功
- 「发送测试通知」点击后给出结果反馈（dev 模式下提示通知归属宿主应用）
- 设置页布局打磨：卡片间距、总开关关闭时供应商列表置灰仅供预览、设置项标题简化
