## 新功能

- **首页卡片拖拽排序**：长按拖动供应商卡片即可调整顺序，托盘菜单里的供应商顺序同步跟随，顺序自动保存，重启不丢。
- **更新内容弹窗**：发现新版本后，横幅不再塞整段说明文字；点「更新内容」即可查看排版后的版本说明（分节、条目、脚注），支持 Esc 或点背景关闭；下载完成后，安装说明固定展示在底部，不随正文滚动。

## 优化

- **托盘「检查更新」有反馈了**：手动检查的三种结果——发现新版、已是最新、检查失败——都会弹系统通知，不再「点了没反应」；托盘菜单里的「检查更新」入口移至 Skill & Plugin 之下。
- **更新按钮即点即显安装中**：点击「立即安装并重启」后立刻显示安装中状态并防止重复点击，不再出现看似无响应的假死。

## 修复

- **停用供应商后托盘菜单行残留**：在主页「供应商配置」停用某供应商后，下拉菜单里它的行此前不会消失，只会变成一行「无数据」占位。现在停用即时生效，行随即消失；全部停用时菜单显示「暂无服务商」。
